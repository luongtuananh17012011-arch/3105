# 3105 UI customization notes — 2026-10-16

This ZIP is based on the supplied `3105-main.zip` source tree. The customization is intentionally limited to presentation:

- Refreshed the adaptive accent colors to a blue/cyan palette with a secondary indigo accent.
- Softened common row-icon tiles, search-field borders, and card outlines.
- Updated the SF Symbols used for the main navigation tabs.
- Added source comments marking the UI-only customization.

The existing file operations, navigation state, persistence/data stores, package handling, and device-management logic were not intentionally edited. This is a source-code change only; it has not been compiled or device-tested in this environment. Build and test in Xcode before installing. The original license and third-party notices are retained; review them before redistribution. The project states that the original 3105 code is GPL-3.0.
